Coach Availability — Setup

Fill this in once and it writes your config.js for you.

1 · Your squad

These are the only names that can sign in.

2 · Firebase

  1. Create a project at console.firebase.google.com (skip Analytics).
  2. Build → Realtime Database → Create database, location europe-west1, start in test mode.
  3. Project settings → Your apps → Web (</>), register an app, and copy the whole firebaseConfig block it shows you.
Leave this empty to build a device-only version you can try first.

3 · Database rules

In the Realtime Database Rules tab, replace everything with this and press Publish. Test mode expires after 30 days, so this step isn't optional.

{
  "rules": {
    "squads": {
      "$squad": { ".read": true, ".write": true }
    }
  }
}

4 · Get your file

Download config.js and upload it to your repo, replacing the one that's there. That's the whole job — nothing else needs editing.
